# The paradox of AI efficiency

AI makes it easier than ever to produce things.

Code, documents, designs, analysis, prototypes. The cost of getting from an idea to an output keeps falling. A task that used to take hours can now take minutes.

It is tempting to call this progress.

And it is progress. But there is a paradox hiding underneath it: **when producing something becomes cheaper, deciding what is worth producing becomes more important.**

## Output is not the same as value

Imagine a developer who can now generate ten implementations in the time it previously took to write one.

That sounds like a tenfold productivity improvement. But what if nine implementations are unnecessary? What if the remaining one is based on a misunderstood requirement? What if reviewing the generated code takes longer than writing it would have?

The bottleneck has moved.

AI reduces the cost of execution, but it does not automatically reduce the cost of judgment. In some cases, it increases it.

We can produce more code without building better software. We can write more documentation without improving understanding. We can generate more ideas without getting closer to a useful decision.

The amount of output is a poor proxy for the amount of value created.

## The new bottleneck is thinking

For a long time, much of knowledge work was constrained by the time required to execute an idea. AI changes that equation.

When execution becomes cheap, the scarce resources become:

- Understanding the actual problem.
- Knowing which constraints matter.
- Evaluating whether an answer is correct.
- Recognizing when the simplest solution is enough.
- Taking responsibility for the final result.

These are not secondary skills. They are the skills that determine whether faster execution produces anything meaningful.

A developer who cannot reason about a system will not become a better engineer simply by generating more code. They may become a faster producer of code they do not understand.

That distinction matters.

## A different picture of productivity

I think we should stop measuring AI productivity primarily by how much it helps us produce.

A better question is: **how much effort does it take to reach a correct, useful outcome?**

Sometimes AI will reduce that effort dramatically. It can handle repetitive work, explain unfamiliar concepts, generate a first draft, or help explore alternatives.

Other times, it creates work that did not exist before: reviewing plausible but incorrect answers, checking assumptions, correcting subtle mistakes, and maintaining things that were generated too quickly.

The tool is useful, but the workflow still needs discipline.

The best results come when a person understands the goal, delegates the parts that can be delegated, and remains responsible for evaluating the outcome.

## More leverage, more responsibility

There is another consequence worth considering.

If everyone can produce more, then producing more is no longer much of a differentiator. Taste, judgment, context, and the ability to identify the right problem become more valuable.

AI does not remove the need for expertise. It changes where expertise is applied.

The paradox is that the easier it becomes to create, the more important it becomes to think before creating.

Efficiency should give us room to do better work, not simply fill the same amount of time with more output.

That is the picture beyond the hype.
